\# 🎵 F-Society Music Bot



\## Features

\- 🎵 \*\*Auto-join voice\*\* – Automatically joins when you play

\- 🛡️ \*\*Adblock\*\* – Ghostery adblock + custom rules

\- 🔍 \*\*Brave Search\*\* – Independent search engine

\- 📁 \*\*Playlist Support\*\* – Full YouTube playlists

\- 🔀 \*\*Queue Management\*\* – Shuffle, clear, view queue

\- 🔊 \*\*Volume Control\*\* – 0-200% volume

\- 🎨 \*\*F-Society Branding\*\* – Professional cyberpunk theme



\## Commands



| Command | Description |

|---------|-------------|

| `!play <song/URL/playlist>` | Play a song (auto-joins voice) |

| `!join` | Manually join voice |

| `!leave` | Leave voice |

| `!pause` | Pause current song |

| `!resume` | Resume current song |

| `!skip` | Skip current song |

| `!stop` | Stop and clear queue |

| `!queue` | Show queue |

| `!shuffle` | Shuffle queue |

| `!clear` | Clear queue |

| `!volume <0-200>` | Set volume |

| `!np` | Now playing |

| `!search <query>` | Search using Brave |

| `!adblock` | Toggle adblock |

| `!help` | Show help |
